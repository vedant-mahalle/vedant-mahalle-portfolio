Welcome to my personal portfolio! This project showcases my journey as a Computer Science student and Full Stack Developer, featuring a modern, responsive design and a robust admin dashboard. Explore my projects, technical skills, and development activity, all in one place.

---

## 🚀 Features

- **Modern, Responsive UI:** Built with Next.js, React, and Tailwind CSS for seamless experiences across devices.
- **Admin Dashboard:** Secure, JWT-protected admin panel for managing contact submissions and viewing statistics.
- **MongoDB Integration:** Contact form submissions are stored and managed via MongoDB.
- **Authentication:** Secure login for admin routes using JWT tokens and environment variables.
- **Animated UI:** Framer Motion for smooth transitions and engaging interactions.
- **Project Filters:** Filter portfolio projects by category and type.
- **GitHub Stats & Contributions:** Visualize development activity with multiple GitHub widgets.
- **Dark/Light Theme:** Toggle between dark and light modes for optimal viewing.

---

## 🛠️ Tools & Technologies Used

- **Frontend:** Next.js, React, TypeScript, Tailwind CSS
- **UI Components:** Shadcn UI, Lucide React, React Icons
- **State & Animation:** Framer Motion
- **Backend/API:** Next.js API Routes
- **Database:** MongoDB (with Mongoose)
- **Authentication:** JWT (jsonwebtoken)
- **Charts & Visualization:** recharts, react-github-calendar
- **Other:** Vercel (deployment), pnpm, ESLint, Prettier
